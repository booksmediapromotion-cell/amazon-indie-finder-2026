# Amazon Indie Author Finder 2026

Modern dashboard for discovering independent authors (100/day limit, 2026+ only).

## Quick Start

```bash
pip install -r requirements.txt
python run.py
```

Open http://localhost:8501

## Features

- ✅ Daily limit: 100 books
- ✅ Date filter: 2026+ only  
- ✅ Genre & state filters
- ✅ Indie scoring (0-100)
- ✅ CSV export
- ✅ SQLite database

## Usage Notes

- Respects rate limits and ToS
- Only public information
- Comply with GDPR/CCPA
- For legitimate research only
